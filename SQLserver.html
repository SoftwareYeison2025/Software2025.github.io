¿Que es SQLserver?

Microsoft SQL Server es un sistema de gestión de base de datos relacional, desarrollado por la empresa Microsoft.


El lenguaje de desarrollo utilizado (por línea de comandos o mediante la interfaz gráfica de Management Studio) es Transact-SQL (TSQL), una implementación del estándar ANSI del lenguaje SQL, utilizado para manipular y recuperar datos (DML), crear tablas y definir relaciones entre ellas (DDL).

Dentro de los competidores más destacados de SQL Server están: Oracle, MariaDB, MySQL, PostgreSQL. SQL Server ha estado tradicionalmente disponible solo para sistemas operativos Windows de Microsoft, pero desde 2016 está disponible para GNU/Linux, y a partir de 2017 para Docker también.


Puede ser configurado para utilizar varias instancias en el mismo servidor físico, la primera instalación lleva generalmente el nombre del servidor, y las siguientes - nombres específicos (con un guion invertido entre el nombre del servidor y el nombre de la instalación).


Historia

Los orígenes de SQL Server se remontan a finales de los años 80, cuando Microsoft buscaba establecer presencia en el mercado de bases de datos. En 1988, Microsoft formó una alianza estratégica con Sybase y Ashton-Tate para adaptar Sybase SQL Server al sistema operativo OS/2. Este proyecto conjunto dio frutos en 1989 con el lanzamiento de SQL Server 1.0, aunque su adopción fue limitada.


La verdadera transformación comenzó cuando Microsoft decidió independizarse de Sybase en 1994. SQL Server 6.0 marcó el inicio de un camino independiente, pero fue con SQL Server 7.0 en 1998 cuando Microsoft demostró su capacidad para innovar, introduciendo un motor de base de datos completamente rediseñado. Este lanzamiento sentó las bases para lo que sería una década de crecimiento explosivo.


El cambio de milenio trajo consigo SQL Server 2000, que consolidó la posición de Microsoft en el mercado empresarial con características avanzadas de inteligencia de negocios. Sin embargo, el punto de inflexión llegó en 2005 con SQL Server 2005, que representó una reinvención completa de la plataforma. La integración con .NET Framework, el nuevo entorno de gestión y las capacidades avanzadas de reporting transformaron a SQL Server en una solución empresarial completa.


En años recientes, SQL Server ha seguido evolucionando para mantenerse relevante en la era de la nube y los grandes datos. La versión 2017 marcó un hito histórico al ser la primera en funcionar nativamente en Linux, demostrando la adaptabilidad de Microsoft a los nuevos tiempos. Hoy, SQL Server continúa siendo un pilar fundamental en la infraestructura de datos de empresas alrededor del mundo.
